# 🌐 Portfólio Pessoal – Projeto de Aprendizado

Este projeto é um **portfólio pessoal desenvolvido como prática inicial de desenvolvimento web**, com o objetivo de aplicar conceitos fundamentais de **HTML e CSS**, além de explorar novas ideias de layout, design e organização de código.

O foco principal deste projeto **não é ser um produto final**, mas sim **servir como um espaço de experimentação, aprendizado e evolução constante**.

---

## 🎯 Objetivos do Projeto

- Praticar conceitos básicos de **HTML5 e CSS3**
- Aprender a estruturar páginas web de forma organizada
- Experimentar estilos visuais modernos (gradientes, blur, glassmorphism, etc.)
- Entender melhor **layout, posicionamento e responsividade**
- Resolver problemas reais que surgem durante o desenvolvimento
- Consolidar novos conhecimentos adquiridos durante os estudos

---

## 🧠 Aprendizados Durante o Desenvolvimento

Durante a construção deste projeto, foram explorados conceitos importantes como:

- Estrutura semântica de páginas HTML
- Organização de layout com sections e containers
- Posicionamento de elementos com Flexbox
- Criação de menus de navegação
- Uso de gradientes e efeitos visuais
- Controle de espaçamento e alinhamento
- Estruturação de CSS para melhor manutenção
- Ajustes visuais e melhorias de usabilidade

Cada etapa do desenvolvimento trouxe novos desafios e oportunidades de aprendizado, tornando este projeto uma parte importante do processo de evolução como desenvolvedor.

---

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3**

## 📚 Propósito Educacional

Este projeto foi desenvolvido com o objetivo de aprender na prática.  
Algumas decisões de código podem não seguir padrões avançados de desenvolvimento, pois fazem parte do processo de experimentação e descoberta.

A ideia é que este projeto evolua ao longo do tempo, acompanhando o crescimento técnico e a aquisição de novos conhecimentos.
